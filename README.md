# CV Application

A simple CV builder built with React. Users can fill out a form to create their CV and edit their information after submitting it.

## Built With

* React
* JavaScript
* CSS

## Usage

1. Fill in the CV form.
2. Submit the form to generate your CV.
3. Use the edit button to make changes.
4. Submit the form again to update your CV.
